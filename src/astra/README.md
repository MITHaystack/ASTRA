# ASTRA User Interface
This software provides services and a web based user interface for the Automated Small Telescope for Radio Astronomy (ASTRA). 

## Description

ASTRA services include data objects, antenna motion control, interface to the RP2040 Antenna Interface (AI),
radio control, imager control, a spectrometer, and a user interface. The user interface provides a dashboard to visualize the sky, control ASTRA motion, collect and observe radio data, and capture images with the integrated optical telescope and camera.
