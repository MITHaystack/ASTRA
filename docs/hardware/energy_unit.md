## Procedure

1. Drill Holes in Enclosure

Note this is a very finicky step!

Be sure to back the plastic with a solid block of wood and drill into that carefully. 

Install the first SMA bulkhead hole using a 6.5 mm / 1/4 inch drill bit measure down from the right enclosure lip bottom approximately 2 inches. Drill carefully even when backed and at moderately high speed. Hand clean hole edges with knife. This hole has the potential to crack the plastic.

Flip to the opposite side and install the second SMA hole using a 6.5 mm / 1/4 inch drill bit measure down from the right enclosure lip bottom approximately 2 inches. Drill carefully even when backed and at moderately high speed. Hand clean hole edges with knife. This hole has the potential to crack the plastic.  

Use a 1 inch spade bit and measure down on the right hand side 25 mm / 1". This should leave clearance below for the SMA and above for the enclosure lip bottom. Drill backed with care at high speed. Stop immediately after cutting the circular hole in the plastic. Hand clean with knife. 

Use a 1.?? spade bit and measure down on the left hand side 25mm / 1". This should leave clearance above for the enclosure lip edge. Drill backed with care at high speed. Stop immediately after cutting the circular hole in the plastic. Hand clean with knife. 

2. Foil tape enclosure interior

3. Cut foam to side

4. Install foam in bottom of enclosure

5. Install cable entries

Install the SMA bulkhead connectors with the flange side on the outside and the washer, lock washer, and nut on the inside. Two of these get installed on opposite sides. 

The 1" spade hole gets the dual USB-C bulkhead connector and cables. Be sure the exterior gasket and cover are on the outside. Thread from outside into hole and insert. It may be necessary to push fairly hard. If necessary  clean and open hole edge with knife. Use nut over cables on the inside to attach.

The 1.?? hole gets the 12V DC power entry bulkhead connector and cable. Be sure the exterior gasket and cover are on the outside. Thread from outside into hole and insert. It may be necessary to push fairly hard. If necessary  clean and open hole edge with knife. Use nut over cables on the inside to attach.

6. Install the SMA cables

The SMA cable entry under the USB cable entry gets a straight SMA RG314 cable for attachement to the software radio. The SMA cable entry on the opposite side is for the USB WiFi adapter that is used to provide a device hotspot. This second entry gets a right angle connector and SMA RG314 cable. It attaches on the other end to the minicircuits 2 GHz bandpass filter and the RP-SMA to Alfa USB WiFi adapter. 

7. Install the power station.

Plug the right angle AC cable intot he side of the Bluetti Elite 30 V2 power station. Install station face up in the foam. This should place the DC and USB cable entries to the left of the unit when facing its controls. 

8. Install the Software Radio

9. Install the external WiFi Adapter

The Alfa USB WiFI adapter and USB cable should be copper foil wrapped around the connection points. Connect to the SMA cable 

10. Install the Computer



11. Install the external WiFI antenna 

Using an RP-SMA adapter, connect the external WiFI antenna from the Alfa Wifi USB adapter to the WiFI SMA bulkhead.
