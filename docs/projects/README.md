# ASTRA Projects

ASTRA projects are efforts requiring several observing sessions. 
Intermediate lessons require the reduction and analysis of data using on 
platform Marimo notebooks. Advanced lessons require the use of ASTRA
via command line tools and in combination with other software on and
off the platform.
